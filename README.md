# 📊 Projeto Final - Análise de Rounds de CS:GO

Este repositório contém um projeto de análise de dados focado em partidas do jogo Counter-Strike: Global Offensive (CS:GO). Através de um conjunto de dados contendo snapshots de rounds, aplicamos técnicas de exploração, limpeza e visualização de dados usando Python e Jupyter Notebook.

## 📁 Arquivos do projeto

- `projeto_final.ipynb`: notebook com toda a análise, gráficos e explicações.
- `csgo_round_snapshots.csv`: dataset com informações detalhadas de cada round.
  
## 🧪 Tecnologias utilizadas

- Python 3
- Pandas
- Matplotlib / Seaborn
- Jupyter Notebook

## 📌 Objetivos do projeto

- Explorar o comportamento de rounds em partidas de CS:GO
- Analisar padrões como: vantagens de lado (CT x TR), uso de armas, mortes por round, entre outros
- Gerar visualizações para facilitar o entendimento dos dados

## 📊 Principais análises realizadas

- Distribuição de vitórias por lado (CT/TR)
- Correlação entre número de jogadores vivos e resultado do round
- Frequência de eventos como planta/desarme da bomba
- Mapas mais jogados (se incluído no dataset)
